PUBLISH WITH GITHUB PAGES:
1. Create a new GitHub repository (for example, sportzen-website).
2. Upload index.html, styles.css, script.js, and the entire assets folder to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.
